# Free model policy

Managed native T3/OpenCode and independent local decisions remain the defaults. Gateway models are an explicit alternative: `STUDIO_MODEL` and `STUDIO_FX_MODELS_JSON` register authoring models; `STUDIO_DECISION_SDK_MODELS_JSON` registers structured generation; `STUDIO_DECISION_EVALUATION_MODELS_JSON` separately registers native evaluation models. An OIDC token or a public model listing does not enable an alternative automatically. No registered Gateway model means an unavailable capability, with no fallback from T3 or local decisions.

Local models advertise artifact edit proposals separately from chat, repository reads and native decisions. The server checks this capability before admitting an edit, when executing a saved edit job, and before publishing a structured proposal. A visual chat request can still use the independent classifier; a non-none classification requires an edit-capable authoring model. Selecting a model never changes another picker or silently falls back to another model. Capability flags describe the supported software contract, not a guarantee that every generated proposal is correct.

Qwen2.5 remains the default chat model and independent native-decision model; its artifact-edit capability is disabled after the bounded authoring assessments rejected invalid proposals. SmolLM2 and Granite also remain unavailable for artifact edit proposals. Optional `qwen3-0.6b-q4-k-m` registers the separately pinned, Apache-2.0 Qwen3 file as an explicit assessment subject with the existing automatic wrapper and resource limits. It is not a decision model or an implicit fallback. Its edit-capability registration is release-gated on a distinct actual authoring assessment; registry and controlled protocol checks alone do not establish that qualification. No thinking, cache, or model-specific prompt override is installed.

Every first-party Gateway SDK attempt passes through `createFreeGateway`. It re-reads the complete public catalog and the chosen model's endpoints without sending credentials to those metadata requests. Both responses need a current HTTP date and an age no greater than 60 seconds. Invocation does not reuse an older price quote. Catalog input/output prices and every advertised endpoint fee must be exact textual zero; unknown fees, omitted required fees, mixed-price endpoints under one provider, virtual models, and ambiguous catalog pricing are refused before inference. Decimal parsing never rounds a small positive price down to zero.

The request pins the verified zero-cost provider allowlist and empty model fallbacks and request credentials. Caller-selected fallback, BYOK, service-tier, caching, provider-defined tools, and other routing options are refused. Production inference targets the canonical Gateway API; owned loopback protocol fixtures require an explicit server-code metadata transport and cannot be enabled through deployment environment variables. This is request validation against current published metadata, rather than an atomic vendor billing-price lock.

The guarded provider exposes only language and native decision/evaluation factories. Unsupported media, batch, hosted-tool and WebSocket factories are absent from its public surface. Standalone Request streams are consumed once with a 16 MiB limit and a 10-second read deadline; canceled, blocked, malformed, locked and oversized bodies cannot trigger price lookup or inference.

Production environment configuration also refuses direct decision APIs and external authoring/design models whose prices cannot be verified. Their protocol adapters remain available to controlled, independently injected fixtures. Browser requests and artifact text cannot opt out of the free-only policy.

The native evaluation alternative uses AI SDK 7's evaluation API and the separate `vercel-evaluation` decision provider. It preserves boolean probabilities, typed choice distributions, rubric scores, refusals, source snapshots, the artifact's own threshold and SQL receipt caching. Missing probabilities remain unscored advice. It never creates confidence by asking a chat model to invent it. Complete oversized requests fail before network I/O. Changing this picker does not change the authoring harness.

On 2026-10-30 the public catalog and endpoint metadata advertised zero prices for the reviewed free language and native evaluation aliases. A separate synthetic attempt on each surface returned HTTP 402 before completing inference, because the connected account still required Gateway credit activation. No purchase, paid fallback, completed Gateway answer or live Gateway acceptance is claimed. Local downloaded models continue to work without Gateway credit activation.

Controlled tests exercise the actual installed SDK request boundary, independent decision profile persistence, native threshold/abstention and cache behavior, price changes, stale/unknown/positive fees, routing rejection, cancellation and zero admitted upstream calls when pricing is unsafe. Owned HTTP fixtures supply their own explicit zero-price metadata; those fixtures are not live-provider evidence.
