## Evidence interpretation

Chromium, PostgreSQL, FFmpeg/ffprobe, HyperFrames CLI, FontTools, Handwired/Z3 and the independent Magnetar prover are actual external tools where named. Paid inference, enterprise identity, authenticated Open Design, a production Vercel deployment, restore and load behavior need their own environment evidence. Passing one category cannot fill another.

Update this matrix as implementation and acceptance land, then record the final release commit and immutable CI/deployment receipts. Open entries are remaining requested work, not approved exclusions.
