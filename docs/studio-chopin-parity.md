It is a feature comparison, not a statement that a landing-page screenshot proves production acceptance. Rows name the implementation and checks; genuine missing software is listed explicitly rather than attributed to unavailable credentials.

The saved documents are research inputs in the shared workspace; the links above identify their public origins. They describe a changing research prototype. This audit uses the observed behavior, including the lifecycle documentation's explicit future-work boundaries, rather than inventing functions implied by the word “parity.”

**Status:** **Local** means implemented with the named local checks. **Different** means the same user capability uses a deliberate Studio contract, described in the row. **Gap G#** identifies a confirmed gap at the original audit baseline; the resolution ledger below records its implementing source and checked local acceptance. The baseline audit is not a claim that the named implementation commits are missing. A fixture passing is never substituted for a gap being implemented. “External” names the particular live acceptance still required when the local implementation exists.
