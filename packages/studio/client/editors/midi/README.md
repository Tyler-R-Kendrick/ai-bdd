# MIDI canvas

`MidiEditor` edits the persisted MIDI artifact with a piano roll and track/note inspectors. Double-click draws a snapped note; dragging moves it and the right edge resizes it. Keyboard arrows move a selected note, Delete removes it, Ctrl/Cmd-D duplicates it, and Ctrl/Cmd-Z undoes it. Native project data retains note velocity/release velocity, program/channel, gain/mute/solo, tempo/meter changes, PPQ and bounded controller/meta/system events. Incoming revisions preserve a dirty local draft and require an explicit latest-version load; viewers can inspect, audition and download but cannot mutate it.

SMF0/1 imports are decoded before the authenticated artifact upload. `sourceSrc` points only to a project-owned admitted MIDI file. An unchanged export fetches its original bytes after reload and preserves them exactly, including running status and opaque metadata. Edited exports use the independent shared SMF codec. SMF has no standard per-track mute metadata: muted and unsoloed parts are omitted from an edited file, while the saved native arrangement retains their notes. Channel controls follow MIDI channel semantics; assigning independent channels avoids shared instruments/controllers.

The browser oscillator synth is an audition tool, not a sampled General MIDI sound bank. It applies tempo-aware note timing and seek, velocity, simple program families, procedural percussion, common volume/expression/pan/sustain controls and a two-semitone pitch-bend range. Other preserved messages and SysEx remain in MIDI exports; the synth does not claim to reproduce every external instrument or message. WAV bounce uses the same voice path in an OfflineAudioContext, renders stereo 44.1 kHz PCM16 with a short release tail, and is limited to 120 seconds and 64 concurrent voices including release tails. Longer or denser scores remain editable and exportable as MIDI. A bounded controller-work budget rejects pathological note/controller combinations before audio allocation. Track data supports up to 32 logical tracks, 10,000 notes/events, 4096 beats, 256 tempo changes, 128 meter changes and a 10 MiB imported source under the shared schema/codec budgets.

Browser acceptance in `tests/midi-editor.spec.ts` uses actual Chromium, authenticated save/reload/upload/export, independent `midi-file` decoding, and FFprobe/FFmpeg PCM analysis. It checks real WAV silence/timing, velocity level differences and the C5 tone, rather than inferring audio from UI labels. The desktop and mobile captures use saved and view-only artifacts respectively. These are local oscillator-rendering and protocol checks; they do not certify an external synthesizer, provider account or hosted media worker.
