# Changelog

## 0.1.0

- `register()` with the catch-all, the World mixin and the session hooks.
- `catchAllPattern()` coexist mode (negative lookahead over native patterns).
- Local binding API (`Given`/`When`/`Then`/`bind`) with descriptions, examples, counter-examples,
  kinds and declared parameters.
- `DaemonClient` over the HTTP JSON mirror, with typed `DaemonError` payloads.
