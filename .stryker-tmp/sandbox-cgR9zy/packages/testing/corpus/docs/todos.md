# Todos

## Adding a todo

Customers add a todo by typing a title into the new todo field and pressing Add. The new todo appears in the list together with the time it was added.

## Sync indicator

A sync indicator on the page shows the last time the list was synced with the server.

Todos are stored per account and are not shared between accounts.
